Passhold 是一款永久免費的密碼管理工具，可自動填入登入資料，保存您的通行金鑰，並產生高強度密碼。您的保險庫會在電腦上加密，使用 Keyrook 帳戶即可同步到您使用的每部電腦。原始碼公開，任何人都能檢視它的運作方式。

自動填入，免輸入
• 每個登入欄位中的按鈕會列出該網站的登入資料，一按即可填入。
• 登入時提議儲存新的登入資料，變更密碼時提議更新。
• 卡片與地址只會在您選擇的付款頁面填入。
• 網站支援通行金鑰時，可用通行金鑰登入。
• 在框架（iframe）內的表單中同樣有效，許多銀行與購物網站的登入頁面都是這樣設計。
• 可用鍵盤快速鍵隨時開啟您的保險庫。

高強度，各不相同
• 密碼產生器：為每個帳戶產生高強度且各不相同的密碼。
• 可選擇長度與字元種類，並排除 0 和 O 這類容易混淆的字元。
• 安全檢查：找出弱密碼與重複使用的密碼，並顯示應先處理的項目。

在每部電腦上同步
• 一個 Keyrook 帳戶，可使用它自己的密碼，或以 Google 或 GitHub 登入。
• 以 Touch ID 或 Windows Hello、PIN 碼或安全金鑰解鎖。
• 由您自行保存的加密備份。

輕鬆搬入，輕鬆離開
• 可從瀏覽器或大多數其他密碼管理工具，以 CSV 檔案匯入登入資料。
• 隨時可匯出為 CSV 檔案或加密備份。您的資料永遠屬於您自己。

只有您能讀取
• 所有內容都在您的電腦上以 AES-256-GCM 加密後才離開電腦。Keyrook 的伺服器會保存同步的內容，但無法讀取，也不知道內容屬於哪些網站。
• 開啟保險庫的金鑰，永遠不會傳到 Keyrook。
• 沒有廣告、追蹤器或分析工具。
• 網站圖示內建於應用程式中，沒有任何伺服器會知道您在哪些網站擁有帳戶。
• 登入資料只會提供給其所屬的網站，偽造的頁面無法取得任何內容。
• 看不見的欄位絕不會被填入，卡片只會在安全頁面上填入。
• 複製的密碼會在一段時間後從剪貼簿清除。
• 開放原始碼：任何人都能在 GitHub 上閱讀程式碼。

永久免費
• 以上所有功能永久免費，對所有人開放。付費方案只會加上額外功能，以上內容永遠不會改為收費。

保險庫中的其他內容
• 卡片、地址與安全備註，可分類到資料夾中，並可加入自訂欄位。
• 垃圾桶會保留您刪除的項目，直到您清空為止；每筆登入資料的舊密碼也會保留。
• 離開時會自動鎖定。
