Passhold 是一款永久免费的密码管理器，可自动填写登录信息，保存您的通行密钥，并生成高强度密码。您的密码库在电脑上加密，使用 Keyrook 账号即可同步到您使用的所有电脑。源代码公开，任何人都可以查看它的工作方式。

自动填写，无需输入
• 每个登录输入框中的按钮都会列出该网站的登录信息，点击一下即可填写。
• 登录时提示保存新的登录信息，更改密码后提示更新。
• 银行卡和地址只会在您选择的结账页面中填写。
• 网站支持通行密钥时，可以用通行密钥登录。
• 在框架（iframe）内的表单中同样有效，许多银行和商店的登录页都采用这种结构。
• 随时可用键盘快捷键打开您的密码库。

高强度密码，各不相同
• 密码生成器：为每个账号生成高强度且各不相同的密码。
• 可选择长度和字符种类，并排除 0 和 O 这类容易混淆的字符。
• 安全检查：找出弱密码和重复使用的密码，并显示应先处理的内容。

在所有电脑上同步
• 一个 Keyrook 账号，可使用它自己的密码，也可使用 Google 或 GitHub 登录。
• 使用 Touch ID 或 Windows Hello、PIN 或安全密钥解锁。
• 您自己保管的加密备份。

轻松迁入，轻松离开
• 可从浏览器或大多数其他密码管理器，用 CSV 文件导入登录信息。
• 随时可导出为 CSV 文件或加密备份。数据始终归您所有。

只有您能读取
• 所有内容都在您的电脑上使用 AES-256-GCM 加密后才离开电脑。Keyrook 的服务器保存同步的内容，但无法读取，也不知道内容属于哪些网站。
• 打开密码库的密钥，永远不会传到 Keyrook。
• 没有广告、跟踪器或分析工具。
• 网站图标内置于应用中，没有任何服务器能得知您在哪些网站上有账号。
• 登录信息只提供给其所属的网站，因此仿冒页面无法获得任何内容。
• 看不见的输入框绝不会被填写，银行卡只在安全页面上填写。
• 复制的密码会在一段时间后从剪贴板中清除。
• 开源：任何人都可以在 GitHub 上阅读代码。

永久免费
• 以上所有功能永久免费，对所有人开放。付费方案只会增加额外功能，以上内容永远不会转为收费。

密码库中的其他内容
• 银行卡、地址和安全笔记，可放入文件夹，并可添加自定义字段。
• 回收站会保留您删除的内容，直到您将其清空；每个登录项的旧密码也会保留。
• 您离开时会自动锁定。
