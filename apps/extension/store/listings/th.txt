Passhold คือตัวจัดการรหัสผ่านฟรีตลอดไป ที่กรอกการเข้าสู่ระบบของคุณอัตโนมัติ เก็บพาสคีย์ และสร้างรหัสผ่านที่แข็งแรง คลังข้อมูลของคุณถูกเข้ารหัสจากต้นทางถึงปลายทางบนคอมพิวเตอร์เครื่องนี้ และซิงก์ระหว่างคอมพิวเตอร์ของคุณด้วยบัญชี Keyrook เป็นโอเพนซอร์ส ทุกคนจึงตรวจสอบได้ว่ามันทำงานอย่างไร

กรอกอัตโนมัติในทุกเว็บไซต์
• คลิกเดียวในช่องเข้าสู่ระบบ เพื่อกรอกบัญชีที่ถูกต้องของเว็บไซต์นั้น
• บันทึกการเข้าสู่ระบบใหม่ขณะที่คุณลงชื่อเข้าใช้ และอัปเดตรายการที่คุณเปลี่ยน
• กรอกบัตรและที่อยู่ตอนชำระเงิน เฉพาะตรงที่คุณเลือกเท่านั้น
• ลงชื่อเข้าใช้ด้วยพาสคีย์บนเว็บไซต์ที่รองรับ
• ใช้ได้กับฟอร์มในเฟรมภายในหน้าเว็บ ซึ่งการลงชื่อเข้าใช้ของธนาคารและร้านค้าหลายแห่งมักสร้างแบบนี้
• ปุ่มลัดบนคีย์บอร์ดเปิดคลังข้อมูลของคุณได้ทุกเมื่อ

แข็งแรงและไม่ซ้ำกัน
• ตัวสร้างรหัสผ่าน: รหัสผ่านที่แข็งแรงและไม่ซ้ำกันสำหรับทุกบัญชี
• เลือกความยาวและชนิดของตัวอักษรได้ และตัดตัวอักษรที่ดูคล้ายกันออก เช่น 0 กับ O
• การตรวจสอบความปลอดภัย: พบรหัสผ่านที่อ่อนและที่ใช้ซ้ำ และแสดงว่าควรแก้อะไรก่อน

ซิงก์ระหว่างคอมพิวเตอร์ของคุณ
• บัญชี Keyrook เพียงบัญชีเดียว ใช้รหัสผ่านของบัญชีเอง หรือลงชื่อเข้าใช้ด้วย Google หรือ GitHub
• ปลดล็อกด้วย Touch ID, Windows Hello, PIN หรือคีย์ความปลอดภัย
• ข้อมูลสำรองที่เข้ารหัสซึ่งคุณเก็บไว้เอง

ย้ายเข้ามาได้ง่าย ออกไปได้ง่าย
• นำเข้าการเข้าสู่ระบบของคุณด้วยไฟล์ CSV จากเบราว์เซอร์หรือตัวจัดการรหัสผ่านอื่นส่วนใหญ่
• ส่งออกได้ทุกเมื่อ เป็นไฟล์ CSV หรือข้อมูลสำรองที่เข้ารหัส ข้อมูลของคุณยังเป็นของคุณ

เป็นส่วนตัวตั้งแต่ต้น
• Zero-knowledge: ทุกอย่างถูกเข้ารหัสด้วย AES-256-GCM บนคอมพิวเตอร์ของคุณก่อนออกไป Keyrook เก็บสิ่งที่คุณซิงก์ แต่อ่านไม่ได้
• คีย์ที่เปิดคลังข้อมูลของคุณจะไม่ไปถึง Keyrook
• ไม่มีโฆษณา ไม่มีตัวติดตาม และไม่มีการวิเคราะห์
• ไอคอนเว็บไซต์มีมาในตัว ดังนั้นไม่มีเซิร์ฟเวอร์ใดรู้ว่าคุณมีบัญชีที่ไหน
• บัญชีจะถูกเสนอเฉพาะบนเว็บไซต์ของตัวเอง หน้าปลอมจึงไม่ได้อะไรเลย
• ช่องที่คุณมองไม่เห็นจะไม่ถูกกรอกเลย และจะกรอกบัตรเฉพาะในหน้าที่ปลอดภัยเท่านั้น
• รหัสผ่านที่คัดลอกจะถูกล้างออกจากคลิปบอร์ดหลังจากผ่านไปสักครู่
• โอเพนซอร์ส: อ่านโค้ดได้บน GitHub

ฟรีตลอดไป
• ทุกอย่างข้างต้นฟรีตลอดไป สำหรับทุกคน แผนแบบจ่ายเงินเพียงเพิ่มฟีเจอร์เสริม และสิ่งเหล่านี้จะไม่มีวันกลายเป็นแบบเสียเงิน

มีในคลังข้อมูลของคุณด้วย
• บัตรชำระเงิน ที่อยู่ และโน้ตที่ปลอดภัย แยกเป็นโฟลเดอร์ พร้อมช่องกำหนดเอง
• ถังขยะที่เก็บสิ่งที่คุณลบ และทุกเวอร์ชันก่อนหน้าของการเข้าสู่ระบบ
• ล็อกตัวเองเมื่อคุณไม่อยู่
